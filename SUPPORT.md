# Support

Use GitHub Issues for reproducible bugs and feature requests. Include the Short
Editor version, macOS version, architecture, and concise reproduction steps.

Before attaching diagnostics, use Support Center's preview. Paths and
transcripts are excluded by default and require separate explicit consent.
Never post credentials, private source media, or unredacted transcripts.

Security vulnerabilities belong in GitHub's private vulnerability reporting
flow described in `SECURITY.md`, not in public issues.
