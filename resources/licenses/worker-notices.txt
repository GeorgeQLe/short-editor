The frozen local worker uses Python 3.12, faster-whisper 1.2.1 (MIT),
CTranslate2 4.8.1 (MIT), PyInstaller 6.21.0 (GPL-2.0-or-later with the
PyInstaller bootloader exception), and their fully hash-pinned dependencies.
Windows bundles also include the Microsoft Visual C++ runtime files required by
CPython and CTranslate2; those files are distributed under Microsoft's
redistributable runtime license.

Exact package versions and artifact hashes are recorded in
resources/worker/requirements.lock (macOS),
resources/worker/requirements.windows-x64.lock (Windows), and the
architecture-specific runtime-manifest.json.
