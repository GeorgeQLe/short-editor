## UAT discovery

The first revision-edit attempt exposed a strict-form defect: the UI copied
persisted rule metadata (`id`, revision, timezone database version, and
timestamps) into the editable strict rule object, so replacement validation
rejected those keys. The form now constructs an explicit editable
`ScheduleRules` snapshot. A component regression proves existing rule saves
send only the seven rule fields plus the separate exact revision.
